# ZMK Config

Personal ZMK firmware configuration for wireless split keyboards.

## Supported Keyboards

- RoKi split ergonomic keyboard

## Build

Firmware is built automatically via GitHub Actions when pushing changes to this repo.

## Usage

1. Clone this repo
2. Edit `config/` keymap files
3. Push to trigger a build
4. Download the `.uf2` artifact from Actions
5. Flash to your keyboard controller

See the [ZMK documentation](https://zmk.dev/docs) for details.
